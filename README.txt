TRS Local Chapter – Gujarat website
===========================
Live address: https://trs-gujarat.netlify.app

Updating the live site
1. Unzip this folder.
2. Open your site on app.netlify.com > Deploys.
3. Drag the unzipped folder onto the drop area. The address stays the same.

What is inside
- index.html          the whole site (all six pages load at once, so switching is instant)
- 404.html            shown for mistyped addresses
- img/                photos (WebP), share image og-image.jpg
- img/people/         put office-bearer headshots here
- fonts/              Red Hat Display, Text and Mono (self-hosted for speed)
- icons/, site.webmanifest   browser tab icon and "Add to Home Screen" icon
- conclave-2027.ics   "Add to calendar" file for the conclave
- netlify.toml, robots.txt, sitemap.xml   hosting and search settings
